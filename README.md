# Vocca — английские слова каждый день

Веб-приложение (PWA) по макету Aura из Figma. Открывается с экрана «Домой» как обычное приложение и работает без интернета. Весь прогресс хранится на телефоне, сервер не нужен.

Внутри: английский A1–B2 (3 038 слов), три режима повторения, тест уровня, 11 групп слов (неправильные глаголы с тренажёром, ложные друзья, идиомы, фразовые глаголы, синонимы и другие). Интерфейс на украинском и русском, тема Aura и Aura Dusk.

## Главное правило: правки точечные

Код устроен так, что почти любая правка — это одна строка или одна таблица.

| Что нужно | Где менять |
|---|---|
| Включить или выключить функцию (тест уровня, группы, прогноз, серию дней, подсказку…) | `src/config.js` → `features`: `true` / `false` |
| Слов в день, новых слов, пауза на ответ, интервалы повторения | `src/config.js` |
| Как проходит занятие: карточки «Я знаю це / Вчити» или прежний «Згадай слово» → оценка | `src/config.js` → `lessonStyle`: `'cards'` / `'recall'` |
| Сколько слов за заход в «Повторити слова, які вчу», в группе, в неправильных глаголах | `src/config.js` → `repeatSize`, `groupSessionSize`, `verbSessionSize` |
| Добавить или исправить слово, перевод, пример | `src/content/en/words.tsv` |
| Объяснение «Що це означає?» и подсказку «Не плутай з…» | там же, колонки `def`, `def_uk`, `def_ru`, `note_uk`, `note_ru` |
| Второй пример к слову | там же, колонки `example2`, `example2_uk`, `example2_ru` |
| Британское написание и транскрипция | там же, колонки `word_uk`, `ipa_uk` (пустые — берётся американский вариант) |
| Поправить пример или пояснение в группе | `src/content/en/groups/<группа>.tsv` |
| Добавить группу слов | таблица в `src/content/en/groups/` + одна строка в `src/content/en/pack.js` |
| Убрать группу | в `src/content/en/pack.js` поставить `//` в начале её строки |
| Поменять порядок групп | порядок строк в `src/content/en/pack.js` |
| Неправильные глаголы | `src/content/en/groups/irregular.tsv` |
| Тексты интерфейса | `src/i18n/uk.js`, `src/i18n/ru.js` |
| Пункты настроек: добавить, убрать, переставить | `src/screens/settings.js` → список `SECTIONS` |
| Ссылки «Умови використання», «Політика конфіденційності», «Підтримка» | `src/config.js` → `links` (пустая — пункт не показывается) |
| Цвета, отступы, скругления, стили текста | Figma → `tools/figma-tokens.json` → `python3 tools/gen-tokens.py` |
| Вид компонента (кнопка, карточка, меню) | `src/theme/components.css` — только переменные, без цветов |

Таблицы `.tsv` открываются в Excel, Numbers и Google Таблицах. Сохраняйте их в том же формате: «текст с разделителями-табуляциями», UTF-8. Строка, которая начинается с `#`, — комментарий.

## Добавить латышский

Пакет уже готов: `src/content/lv/` (208 слов, черновик — переводы стоит проверить с носителем).

1. Откройте `src/content/index.js`.
2. В строке `// import lv from './lv/pack.js';` уберите `//` в начале.
3. В строке `export const COURSES = [en];` допишите `lv`: `export const COURSES = [en, lv];`.

На первом экране появится карточка «Latviešu», в настройках — выбор языка. Группы для латышского добавляются так же, как для английского: таблица в `src/content/lv/groups/` и строка в `src/content/lv/pack.js`. Пока групп нет, вкладка «Групи» для латышского не показывается.

Другой язык — так же: скопируйте папку `lv`, поменяйте в `pack.js` код, название и голос (`tts`), положите свою `words.tsv` и добавьте язык в `COURSES`.

## Группы слов

Каждая группа — строка в `src/content/en/pack.js` и таблица в `groups/`. У строки есть `type` — как выглядит экран группы:

- `relation` — слово и связанные с ним слова (экраны 11, 19–27). Одна строка таблицы — один экран.
- `irregular` — неправильные глаголы (экраны 12, 12b, 12e, 12f). Глаголы учатся только в группе, в ежедневное занятие не попадают.

Колонки таблицы `relation`:

| Колонка | Что это |
|---|---|
| `word`, `ipa`, `uk`, `ru`, `level` | исходное слово, транскрипция, перевод, уровень |
| `to1`, `to1_ipa`, `to1_uk`, `to1_ru` | связанное слово (до трёх: `to2…`, `to3…`) — у каждого кнопка «+ Вчити» |
| `ex1`, `ex1_uk`, `ex1_ru` | пример (до трёх). Слово в `[квадратных скобках]` подчёркивается |
| `note_uk`, `note_ru` | пояснение внизу экрана |
| `link` | для «Сталі вирази»: глагол в связке «+ make» и в заголовке «Чому саме make» |
| `literal_uk`, `hint_uk` (и `_ru`) | для идиом: «дослівно…» и короткое пояснение значения |

Подписи блоков («Порівняй», «Чому плутають»), связку между карточками («≠ не плутай») и название группы задаёт строка в `pack.js`. У идиом `meaning: true`: большая карточка показывает значение, а «Вчити» добавляет саму идиому.

Слово, добавленное кнопкой «+ Вчити», попадает в ежедневное занятие первым среди новых. Если его нет в `words.tsv`, оно сохраняется в прогрессе вместе с переводом и примером из группы.

Колонки `irregular.tsv`: `v1`, `v2`, `v3`, `uk`, `ru`, `level`, `fakes` (неверные варианты для тренажёра через запятую), `hint` (тип подсказки из `verbHints` в `pack.js`), `ipa1`–`ipa3`, `note_uk` / `note_ru`, примеры `ex1`–`ex3`. Сложность («Легко / Середньо / Складно») считается сама: все формы одинаковые, две одинаковые или все разные.

## После правок

```
python3 tools/check-content.py   # проверить таблицы: уровни, переводы, повторы, скобки
python3 tools/make-sw.py         # обновить список файлов для работы без интернета
```

Второй скрипт нужен после любой правки: без него телефон может показывать старую версию.

## Посмотреть на компьютере

В папке приложения выполните `python3 -m http.server 8000` и откройте http://localhost:8000. Двойной щелчок по `index.html` не сработает: браузер не даст прочитать таблицы слов с диска.

## Выложить на GitHub Pages и поставить на iPhone

1. Откройте репозиторий на github.com → **Add file → Upload files**.
2. Перетащите **содержимое** папки `vocca` (не саму папку): `index.html` должен оказаться в корне. **Commit changes**.
3. **Settings → Pages**: Source — **Deploy from a branch**, Branch — **main**, папка **/ (root)** → **Save**. Через 1–2 минуты появится адрес вида `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/`.
4. На iPhone откройте адрес в **Safari** → «Поделиться» → **На экран «Домой»**.

Если в репозитории лежит прошлая версия, сначала удалите старые папки `src`, `fonts`, `tools` и файлы `sw.js`, `index.html`, `manifest.webmanifest`, потом загрузите новые. Прогресс новой версии хранится отдельно и начнётся заново.

## Как устроено

```
index.html, manifest.webmanifest, sw.js   оболочка, установка на телефон, работа без интернета
lib/preact-htm.js                         библиотека интерфейса (сборка не нужна)
src/config.js                             ★ функции и значения по умолчанию
src/content/                              ★ языки: en (включён), lv (готов, выключен)
  index.js                                список языков и загрузка таблиц
  en/pack.js, en/words.tsv, en/groups/    пакет английского: группы, слова, таблицы групп
src/groups/                               типы экранов групп: relation.js, irregular.js
src/screens/                              экраны: onboarding (01–03), level-test (02a–02d), today (04),
                                          lesson (05–08), groups (09), words (18, 04a), settings (10)
src/ui/kit.js, src/ui/icons.js            компоненты Aura и иконки из Figma
src/core/                                 логика: store (прогресс), srs (режимы повторения),
                                          session (план на день и занятие), stats, level-test, tts
src/i18n/                                 тексты интерфейса uk / ru
src/theme/                                tokens.css (из Figma), base.css, components.css
tools/                                    скрипты: токены, проверка таблиц, кэш
```

Новый экран: файл в `src/screens/` и строка в `ROUTES` в `src/app.js`. Новый тип группы: файл в `src/groups/` и строка в `src/groups/index.js`.

## Режимы повторения

- **Розумний** — интервал растёт от оценки «Забуто · Важко · Знаю · Легко». «Забуто» возвращает слово в этом же занятии.
- **Фіксований** — лестница 15 хв → 2 год → 4 год → 1 день → 3 дні → 1 тиждень → 2 тижні → 1 місяць. Оценки «Не пам’ятаю / Пам’ятаю».
- **Раз на день** — лестница в днях, повторения один раз в день.

Интервалы — `src/config.js` → `modes`. Слово «вивчене», когда следующий повтор не раньше чем через 21 день (`learnedAfterDays`).

С 15.11.2026 занятие идёт карточками (`lessonStyle: 'cards'`): «Я знаю це» — слово сразу во «Вивчено» и больше не показывается; «Вчити» — слово вернётся по расписанию выбранного режима (новое — на первую ступень: в умном режиме через день). Оценки выше работают при `lessonStyle: 'recall'`. Лимиты «Слів на день» и «Нових слів» — только план на день: после него на главной «Ще 5 нових слів», а «Повторити слова, які вчу» доступно всегда и расписание не сдвигает. Знакомые слова план не тратят. Неправильные глаголы — без тренировки: карточки по 20, в конце итог как в группах.
